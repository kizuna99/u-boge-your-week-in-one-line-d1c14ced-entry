A make.fun entry for [Your Week in One Line](https://make.fun/bounty/u-boge-your-week-in-one-line-d1c14ced).

The program (`main.ts`, Node 22, no dependencies) writes one line to `/output/entry.txt`:

> Shipped Monday, rolled back three times, apologised at 3 a.m. to a database named prod-final-v2.

That line is 96 characters — inside the competition's 1–100 character gate — and sums up the week in a single arc: a Monday ship, three rollbacks, and a 3 a.m. apology to a database whose name (`prod-final-v2`) tells its own story.

## Run

```sh
node main.ts
# writes the line to /output/entry.txt (or ./output/entry.txt when /output is not writable)
```
